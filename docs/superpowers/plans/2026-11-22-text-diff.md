# Text Diff Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A standalone, offline, single-file browser tool that diffs two texts (line + word level) with Unified / Side-by-side and Hide-unchanged toggles, Ignore whitespace / Ignore case options and a per-box Sort button.

**Architecture:** Pure diff logic in `src/diff.js` (global `TextDiff`, also `module.exports`), tested with plain Node. UI in `src/app.js`. `scripts/build.js` inlines CSS/JS into `dist/index.html`. Same shape as `~/myapp/env_json_converter`.

**Tech Stack:** Vanilla HTML/CSS/JS (classic scripts), Node 18+ for tests/build only, GitHub Actions + Pages.

**Spec:** `docs/superpowers/specs/2026-11-22-text-diff-design.md`
**Reference project:** `/home/hh/myapp/env_json_converter` (copy build, workflows, header, colour tokens, test harness style from there).

## Global Constraints

- No runtime or dev dependencies; no CDN, fonts or network calls. `package.json` has no `dependencies`/`devDependencies`.
- Classic `<script src>` tags, not ES modules; `src/index.html` must work from `file://`.
- `src/diff.js` has no DOM access; all UI in `src/app.js`.
- User text is rendered only via `textContent` / text nodes — never `innerHTML` with user text.
- Responsive (desktop / phone) and light/dark via `prefers-color-scheme`.
- Author "Hossam Hamdy", MIT license, GitHub link `https://github.com/hosamhamdy258/text-diff`, live URL `https://hosamhamdy258.github.io/text-diff/`.
- Commits: no `Co-Authored-By` or any AI attribution line.
- Working dir for every command: `/home/hh/myapp/text_diff` (git repo already initialised on `main`, spec committed).

## Review Focus

1. **Huge inputs** (20,000-line log with a few edits): `diffLines` must finish well under 1 s; rendering builds rows with a `DocumentFragment`. → perf test in Task 2.
2. **One giant line** (1 MB minified JSON on one line, changed): word diff must not hang; pairs whose combined token count exceeds 10,000 skip word diff (row has no `words`, whole line shown as changed). → test in Task 3.
3. **HTML-looking text** (`<img src=x onerror=alert(1)>`) must show literally. → `grep innerHTML src/app.js` empty + manual check in Task 5.
4. **Whitespace-only vs empty lines and emoji/Arabic** with options on: `"   "` equals `""` under Ignore whitespace; word tokens never split a surrogate pair. → tests in Tasks 2–3.
5. **Toggling after editing a box without re-Compare**: result must still reflect the snapshot from the last Compare, not the live boxes. → manual check in Task 5.

### Task 2: `diffLines` (line diff with options)

**Files:**
- Modify: `src/diff.js`, `test/diff.test.js`

**Interfaces:**
- Consumes: `splitLines`.
- Produces: `TextDiff.diffLines(a: string, b: string, opts?: { ignoreWhitespace?: boolean, ignoreCase?: boolean }) → Row[]` where
  - `{ type: 'equal', oldNo, newNo, text, newText? }` — `text` is the old line; `newText` only when raw new line !== raw old line.
  - `{ type: 'delete', oldNo, newNo: null, text, words? }`
  - `{ type: 'insert', oldNo: null, newNo, text, words? }`
  - Line numbers are 1-based. Within each change block all `delete` rows come before all `insert` rows. (`words` added in Task 3.)
- Internal (reused by Task 3): `myers(aKeys: any[], bKeys: any[]) → Array<'equal'|'delete'|'insert'>` — minimal edit script, deletes before inserts within a block.

- [ ] **Step 1: Write failing tests** (helper `types = rows => rows.map(r => r.type[0]).join('')`, `rebuild(rows, side)`: old = non-insert rows' `text`; new = non-delete rows' `newText ?? text`):

```js
t('identical', () => eq(types(diffLines('a\nb', 'a\nb')), 'ee'));
t('both empty', () => eq(diffLines('', ''), []));
t('one empty', () => eq(types(diffLines('', 'a\nb')), 'ii'));
t('all different', () => eq(types(diffLines('a\nb', 'c\nd')), 'ddii'));
t('change middle', () => eq(diffLines('a\nb\nc', 'a\nx\nc'), [
  { type: 'equal', oldNo: 1, newNo: 1, text: 'a' },
  { type: 'delete', oldNo: 2, newNo: null, text: 'b' },
  { type: 'insert', oldNo: null, newNo: 2, text: 'x' },
  { type: 'equal', oldNo: 3, newNo: 3, text: 'c' }]));
t('insert start/end', () => eq(types(diffLines('b', 'a\nb\nc')), 'iei'));
t('CRLF == LF', () => eq(types(diffLines('a\r\nb\r\n', 'a\nb')), 'ee'));
t('trailing newline ignored', () => eq(types(diffLines('a', 'a\n')), 'e'));
t('unicode', () => eq(types(diffLines('🎉\nمرحبا', '🎉\nمرحبا!')), 'edi'));
t('ignore ws', () => eq(diffLines('a  b \n   ', ' a b\n\n', { ignoreWhitespace: true }),
  [{ type: 'equal', oldNo: 1, newNo: 1, text: 'a  b ', newText: ' a b' },
   { type: 'equal', oldNo: 2, newNo: 2, text: '   ', newText: '' }]));
t('ignore case', () => eq(types(diffLines('ABC', 'abc', { ignoreCase: true })), 'e'));
t('options off by default', () => eq(types(diffLines('ABC', 'abc')), 'di'));
```

  Fuzz (seeded PRNG, e.g. mulberry32(1)): 3,000 pairs of 0–12 lines drawn from `['a','b','c','',' a','🎉']`:
  - `rebuild(rows,'old') === splitLines(A)` and `rebuild(rows,'new') === splitLines(B)`;
  - deletes + inserts === `n + m − 2·LCS(n,m)` (brute-force DP LCS in the test) — proves minimality;
  - in every maximal non-equal run, no `insert` precedes a `delete`.

  Perf: `diffLines` on two 5,000-line fully different texts, and on a 20,000-line text vs. copy with 50 random line edits, each `< 1000 ms` (`Date.now()`).

- [ ] **Step 2: Run** `npm test` → FAIL.
- [ ] **Step 3: Implement.** Normalise keys: `ignoreWhitespace` → `s.replace(/\s+/g, ' ').trim()`; `ignoreCase` → `toLowerCase()`. Map keys to integer ids. In `myers`: strip common prefix/suffix; remove elements whose id never appears on the other side (they can never match, so LCS is unchanged) and diff the remaining with Myers' linear-space middle-snake divide-and-conquer (Myers 1986 §4b); then merge removed elements back as delete/insert in original order and normalise every change block to deletes-then-inserts. Build rows from the op list, adding `newText` per the interface.
- [ ] **Step 4: Run** `npm test` → all pass, perf lines under 1000 ms.
- [ ] **Step 5: Commit** `git commit -am "Add line diff with ignore options"`

### Task 3: Word diff on paired changed lines

**Files:**
- Modify: `src/diff.js`, `test/diff.test.js`

**Interfaces:**
- Consumes: `myers`, `diffLines` rows.
- Produces: `words: Array<{ type: 'equal'|'delete'|'insert', text }>` on paired rows: a delete row's `words` contain only `equal`/`delete` parts (its own text in order); an insert row's only `equal`/`insert`. Joining a row's `words[].text` === its `text`. Also `TextDiff.tokenize(s: string) → string[]`.

- [ ] **Step 1: Write failing tests.**

```js
t('tokenize', () => eq(tokenize('DB_PORT=5432 ok'), ['DB_PORT', '=', '5432', ' ', 'ok']));
t('tokenize unicode', () => eq(tokenize('مرحبا 🎉!'), ['مرحبا', ' ', '🎉', '!']));
t('word pair', () => {
  const r = diffLines('DB_PORT=5432', 'DB_PORT=6543');
  eq(r[0].words, [{ type: 'equal', text: 'DB_PORT=' }, { type: 'delete', text: '5432' }]);
  eq(r[1].words, [{ type: 'equal', text: 'DB_PORT=' }, { type: 'insert', text: '6543' }]);
});
t('pair by index, extras plain', () => {
  const r = diffLines('a1\nb1', 'a2\nb2\nc2');   // d d i i i
  eq(r.map(x => !!x.words), [true, true, true, true, false]);
});
t('word diff honours ignoreCase', () => {
  const r = diffLines('Foo bar', 'foo baz', { ignoreCase: true });
  eq(r[0].words.filter(w => w.type !== 'equal').map(w => w.text), ['bar']);
});
t('giant line skips word diff', () => {
  const a = 'x '.repeat(6000), b = 'y '.repeat(6000);
  const r = diffLines(a, b); eq(r.map(x => x.words), [undefined, undefined]);
});
```

  Fuzz: for random paired rows, joined `words` text === row `text`.

- [ ] **Step 2: Run** `npm test` → FAIL.
- [ ] **Step 3: Implement.** `tokenize` with `/[\p{L}\p{N}_]+|\s+|[^\p{L}\p{N}_\s]/gu`. For each change block, pair the i-th delete with the i-th insert (`i < min(dels, ins)`). Token keys: whitespace tokens → `' '` when `ignoreWhitespace`; lowercase when `ignoreCase`. Skip when combined token count > 10,000. Merge adjacent same-type parts.
- [ ] **Step 4: Run** `npm test` → all pass.
- [ ] **Step 5: Commit** `git commit -am "Add word-level diff on changed lines"`

  - 20 equal lines, change at line 10 → `[skip 6, 3 equal, d, i, 3 equal, skip 7]` (counts exact).
  - Change at line 1 → no leading skip; change at last line → no trailing skip.
  - Two changes 6 equal lines apart → no skip between; 7 apart → `3 equal, skip 1, 3 equal`.
  - Rule: a leading/trailing unchanged run is collapsed only if longer than 3, a middle run only if longer than 6; the skip row replaces exactly the hidden lines.
